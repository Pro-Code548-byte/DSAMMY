# DSAMMY — Film Production & Talent Development

A professional website for DSAMMY, a film production company that discovers, nurtures, and empowers young talents across writing, production, technology, photography, and comics.

## Pages

| Route | Page |
|-------|------|
| `/` | Home — Hero, 5 division cards, CTA |
| `/about` | About — Mission, stats, vision, values |
| `/writes` | DSAMMY Writes — Screenwriting & story development |
| `/production` | DSAMMY Production — Film & media production |
| `/studio` | DSAMMY Studio — Photography & videography |
| `/comics` | DSAMMY Comics — Comic art & illustration |
| `/tech` | DSAMMY Tech — Film technology & innovation |
| `/contact` | Contact — Form + WhatsApp integration |

## Tech Stack

- **React 19** with React Router v7
- **Vite 8** — build tool
- **CSS** — custom styles with CSS custom properties
- **Google Fonts** — Cinzel (headings), Inter (body)

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploying to Vercel

### Option 1: Vercel Dashboard (recommended)

1. Push this repo to GitHub
2. Go to [vercel.com](https://vercel.com) and click **Add New → Project**
3. Import your GitHub repository
4. Vercel will auto-detect Vite — click **Deploy**

### Option 2: Vercel CLI

```bash
npx vercel login
npx vercel --prod
```

The `vercel.json` file is already configured for SPA routing.
